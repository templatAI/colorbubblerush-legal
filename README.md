# Color Bubble Rush — pages légales

Politique de confidentialité du jeu **Color Bubble Rush**, éditée par Cavarats.

Ce dépôt est public parce que Google Play et AdMob exigent une adresse
consultable sans connexion. Il ne contient **que cette page** : le code du jeu
reste dans son dépôt privé.

La source fait autorité dans le dépôt du jeu (`docs/index.html`) ; ce dépôt
n'en est qu'une copie publiée.

Page en ligne : https://templatai.github.io/colorbubblerush-legal/
